# world-of-slime-assets

Asset của game web **Thế Giới Slime** (`games/world-of-slime` trong
[survivor-web-hub](https://github.com/poke5121999-art/survivor-web-hub)), bóc từ bản
World of Slime Demo (TEAM42) cài trên Steam.

Không sửa tay ở đây. Mọi tệp do các tool trong `games/world-of-slime/tools/` của
survivor-web-hub sinh ra; chạy lại tool rồi commit.

Phục vụ qua GitHub Pages: https://poke5121999-art.github.io/world-of-slime-assets/
